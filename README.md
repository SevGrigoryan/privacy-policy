# Privacy Policy

**Last updated: May 16, 2026**

## Overview
This app (n8n Video Publisher) is a personal automation tool 
that publishes videos to social media platforms including 
YouTube, Facebook, Instagram, TikTok, and LinkedIn.

## Data Collection
This app does not collect or store any personal data from users. 
All data processed by this app is limited to video content 
provided by the app owner for publishing purposes.

## Third Party Services
This app interacts with the following platforms:
- YouTube (Google)
- Facebook (Meta)
- Instagram (Meta)
- TikTok
- LinkedIn

Each platform's own privacy policy applies to data processed 
through their APIs.
